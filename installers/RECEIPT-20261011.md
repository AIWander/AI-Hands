## Deviations from the packet (all deliberate)

1. Uninstall guard: `-Uninstall` removes a hands entry only when its command is -HandsExe, and reports any
   other entry as `skipped foreign` (-Force overrides). Without this guard, the installer's [UninstallRun]
   would delete hand-made entries, such as this machine's gateway hands entries.
2. A TOML "hands block" includes its own sub-tables (`[mcp_servers.hands.*]`), so -Force and -Uninstall never
   leave orphaned `[mcp_servers.hands.tools.x]` tables. Trailing comment and blank lines stay with the next
   table.
3. Extra statuses: `would write` / `would remove` (dry-run), `nothing to remove`, `skipped foreign`, `error`.
4. -ConfigRoot is hermetic. One folder stands in for APPDATA, LOCALAPPDATA and USERPROFILE, and the Appx and
   PATH probes are skipped, so the tests need a claude.exe marker file. Added -LogPath, which the installer
   uses to show the result on its finish page.
5. In the .iss, a `%LOCALAPPDATA%\Packages\Claude_*` folder stands in for Get-AppxPackage, so the wizard does
   not start PowerShell to draw the picker. The writer itself still calls Get-AppxPackage. UsePreviousSetupType=no
   lets detection, not the last run, decide what is ticked.
6. Duplicate hands tables (the old Add-Content anti-pattern) are repaired to one on -Force.
7. Inline or dotted-key hands definitions are detected. They count as "existing", but are never rewritten
   (error with -Force).
8. Own JSON serializer, so output is identical on PS 5.1 and 7. On 7.5 `-DateKind String` keeps ISO dates
   verbatim; pwsh 7.0-7.4 would re-emit them in round-trip format, but the installer uses PS 5.1.
9. .gitignore gains `/mcpb/server/`, so the 22 MB staged binary is not committed.
